# Cburnett chess pieces

The 12 SVGs in this folder are the "Cburnett" chess piece set by Colin M.L. Burnett,
from Wikimedia Commons (`Chess_xxt45.svg`). Triple-licensed **GPL v2+ / BSD / GFDL**;
used here under the BSD terms.

`src/trainer.py` inlines their inner markup as `<symbol>` elements in the generated
`outputs/trainer/blunder_trainer.html` so the page needs no external image requests.

Filename stems: `l` = light (white) pieces, `d` = dark (black), `t` = the standard variant.
